# NETWALKS-AARON-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP
My first cybersecurity lab setup repo
## STEPS
Download & install 7-zip: https://7-zip.org/download.html 
Download & install Virtualbox on your laptop/PC: https://virtualbox.org/wiki/Downloads
Configure the network settings on your Virtualbox (create NATNetwork in 10.0.0.0/24)
Download & import Kali Linux Virtual Machine in your Virtualbox: https://kali.org/get-kali 
Setup the IP configuration of Kali Linux
Take snapshot of the VM
